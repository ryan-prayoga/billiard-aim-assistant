# Billiard Aim Assistant

Real-life PWA aim helper for billiards.

Live: https://billiard.ryanprayoga.dev

## Flow

1. Capture/upload pool table photo
2. Tap cue ball center
3. Tap object ball center
4. Tap target pocket
5. Optional: calibrate ball diameter by tapping two ball edges
6. Drag markers for precision
7. App renders ghost ball, contact point, aim line, object path, tangent cue-ball path, cut angle

## Dev

```bash
npm install
npm run dev
npm run build
```
