# Billiard Aim Assistant

Real-life PWA aim helper for billiards.

Live: https://billiard.ryanprayoga.dev

## Flow

1. Capture/upload pool table photo
2. Optional: set 4 table corners clockwise to unlock 6 pocket presets
3. Tap cue ball center
4. Tap object ball center
5. Pick/tap target pocket
6. Optional: calibrate ball diameter by tapping two ball edges
7. Drag markers, zoom in for precision
8. App renders ghost ball, contact point, aim line, object path, tangent cue-ball path, cut angle

## Dev

```bash
npm install
npm run dev
npm run build
```
